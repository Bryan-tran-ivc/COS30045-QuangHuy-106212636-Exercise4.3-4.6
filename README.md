# Exercise 4 — Bar chart

This page shows the number of TV models for each brand. `js/main.js` loads the CSV, converts counts to numbers, prints a few values in the console, then draws and labels the bars with D3.

The numbers in `data/tvBrandCount.csv` are practice values. Replace the file with your own export before presenting the results as real data.

To open the page, run this command in this folder:

```bash
python3 -m http.server 5500
```

Then visit `http://localhost:5500`.
